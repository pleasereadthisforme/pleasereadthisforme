# Activity UI

설치형 Windows 호스트와 로컬 개발 브라우저가 사용하는 정적 작업 화면입니다.
별도 프런트엔드 빌드 단계 없이 Python 패키지에 포함됩니다.

| 파일 | 역할 |
| --- | --- |
| `index.html`, `style.css` | 화면 구조·반응형 배치 |
| `app.js` | 폴더·문서 탐색, 대화와 실행 과정 |
| `semantic.js` | 문서 준비·임베딩 UI |
| `storage.js` | 앱 저장소 조회·삭제 UI |
| `theme.js`, `ux.js` | 테마와 공통 UI 동작 |
| `characters.js`, `character-*.png` | 실제 화면에 사용하는 캐릭터·모션 |

캐릭터 PNG는 실행 리소스입니다. 제작 시안·원화·모션 실험 페이지는 배포 자산에 포함하지 않습니다.
작업 화면은 로컬 서버 또는 설치형 호스트를 통해 엽니다.
서버 인증을 거쳐 사용하며 HTML 파일을 직접 여는 방식은 지원하지 않습니다.
`?dev=1`은 개발 설정을 표시할 뿐 인증을 우회하지 않습니다.

파일명 클릭은 등록 폴더의 검증된 원본 경로를 기본 앱으로 여는 API를 사용합니다.
PDF 뷰어나 문서 사본을 이 UI에 추가하지 않습니다.
화면의 비용·외부 전송 안내와 삭제 확인은 해당 서버 동작에 맞추어 유지해야 합니다.
