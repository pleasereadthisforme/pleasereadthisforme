입력·보관 방식
키 입력은 별도의 가림 입력창에서 처리합니다. 저장·삭제 후 변경 적용을 위해 앱이 재시작됩니다.
  • 설치형 앱의 키는 Windows 자격 증명 관리자에 사용자·앱 채널별로 보관합니다.
  • 설정 화면에는 저장된 키 값을 표시하지 않습니다.
  • 등록 여부는 키 유효성이나 잔액을 확인한 결과가 아닙니다.


앱 저장 위치와 사용량을 확인하고 정리합니다. 원본 문서는 삭제하지 않습니다.


문서 처리 결과·임베딩·대화 기록을 백업합니다. 원본 문서와 API 키는 제외되며 백업은 암호화되지 않습니다.

데이터 저장과 운영자
원본 파일은 선택한 폴더에, 앱이 생성한 처리 결과·대화·설정은 사용자 기기의 로컬 저장소에 보관합니다. 앱은 문서·질문·답변·API 키·사용 기록을 운영자 ayaan에게 전송하지 않으며, 운영자 서버를 경유하지 않습니다.


OpenAI 전송·처리와 비용
질문·대화 문맥·필요한 문서 본문·경로·도구 출력은 사용자 API 키로 OpenAI에 직접 전송될 수 있습니다. 답변 전 원격 토큰 계산에도 입력이 전송됩니다. 의미 검색은 검색어와 임베딩 대상 본문을, 승인한 문서 준비는 페이지·이미지를 전송합니다. 폴더 등록만으로 전체 파일을 전송하지 않습니다.
전송된 데이터는 API 키가 속한 계정·조직·프로젝트에 적용되는 OpenAI 약관·계약과 데이터 설정에 따라 처리됩니다. 앱은 이 설정을 변경하지 않습니다.
API 데이터는 기본적으로 모델 학습에 사용되지 않으며, 별도 데이터 공유에 동의했다면 해당 설정이 적용됩니다. ChatGPT의 학습 설정과는 별개입니다. 학습 제외는 무보관을 뜻하지 않으며, store=false도 무보관을 보장하지 않습니다.
비용은 사용자 API 계정에 청구됩니다. 견적은 비용 상한을 보장하지 않으며, 중단해도 이미 전송된 데이터나 발생한 비용은 되돌릴 수 없습니다.


로컬 보관과 삭제
문서 처리 결과·임베딩·대화·출처·실행 기록과 요청/응답 snapshot을 앱 저장소에 보관합니다. 본문·경로가 포함될 수 있으며 자동 만료하지 않습니다. 설정의 앱 데이터에서 범위별로 정리할 수 있습니다.
연결만 해제하면 데이터는 남습니다. 문서 처리 결과를 삭제해도 이전 대화의 출처는 남을 수 있습니다. 공유 참조·별도 백업은 남을 수 있으며 원본 파일은 삭제하지 않습니다. 백업은 암호화되지 않습니다. 앱 제거는 앱 데이터 삭제가 아니며 DB 논리 삭제는 물리적 완전 소거 보장이 아닙니다.


키·브라우저 저장소
Windows 키는 OS 자격 증명 관리자로 보관하고 입력은 별도 가림 입력창을 사용합니다. 키 삭제는 로컬 저장분 삭제이며 제공자 키 폐기는 별도입니다. 테마·개발 웹 이름은 localStorage, 개발 웹의 로컬 API 인증 토큰은 sessionStorage를 사용합니다. 이 토큰은 OpenAI 키가 아닙니다.
